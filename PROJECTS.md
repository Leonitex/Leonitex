# Project Portfolio

This page summarizes several projects I am actively developing. The main repositories are private while they are being built and reviewed, so this portfolio focuses on the problem each project is trying to solve, the systems involved, and what I am learning from the work.

## CyberKnight

**Status:** In active development  
**Type:** Educational RPG / technical learning project

CyberKnight is an educational RPG built around the idea that technical learning can be part of gameplay rather than a separate lesson screen.

The project is designed to teach practical concepts from Python, cybersecurity, and IT support through interactive challenges. One of the central design ideas is evidence-first troubleshooting: the player gathers information, inspects symptoms, and makes a diagnosis instead of receiving an automatic answer.

### Areas I have worked on

- Godot project structure and gameplay systems
- GDScript and Python-related learning content
- Dialogue and progression systems
- Save/load behavior
- Interactive troubleshooting mechanics
- Automated validation and testing
- Git branching and milestone-based development
- AI-assisted implementation, review, debugging, and documentation
- Maintaining source-of-truth project documentation for multi-agent workflows

### What I am learning

CyberKnight has been one of my main ways of practicing how to break a large idea into smaller milestones, keep implementation aligned with design goals, test generated code instead of trusting it automatically, and balance technical systems with user experience.

## CatScan

**Status:** In active development  
**Type:** Android budgeting and expense-management application

CatScan started from a practical budgeting problem: receipts and everyday spending are often tedious to enter correctly. The project explores how an Android application can make that process easier through receipt scanning, structured extraction, categorization, and budgeting workflows.

### Areas I have worked on

- Kotlin and Android development
- Jetpack Compose UI
- OCR and receipt text extraction
- Parsing totals and receipt line items
- Expense categorization
- Budget and savings structures
- Usability iteration based on failed scans and incorrect classifications
- GitHub Actions Android builds
- APK validation and debugging
- Privacy-conscious handling of sample data

### What I am learning

CatScan has pushed me to think about software less as a collection of features and more as a complete product experience. A technically working scanner is not enough if the results are inaccurate, the categories are confusing, or the user has to fix everything manually.

## JarvisCall

**Status:** Experimental development  
**Type:** Android AI-assistant workflow

JarvisCall explores how an assistant could proactively deliver a contextual briefing through a call-like experience, request approval when necessary, and preserve enough context to continue the work afterwards.

The project is intentionally concerned with authorization and boundaries: the assistant should know what it is allowed to do, why it contacted the user, and what context belongs to that interaction.

### Areas I have worked on

- Kotlin and Android application structure
- Call-style UI and interaction concepts
- Context handoff between assistant workflows
- Calendar-driven triggers
- Approval and authorization boundaries
- Voice-assistant integration experiments
- Security review and configuration hygiene
- Testing and iterative debugging

### What I am learning

JarvisCall is helping me think more deeply about AI systems as products with state, permissions, context, and failure modes rather than simply chat interfaces.

## Development approach

Across these projects I commonly use:

- Git and GitHub for version control
- Small milestone-driven branches
- Automated tests and validation where practical
- Documentation of important technical decisions
- AI coding assistants and agentic workflows as development tools
- Manual review for major product, visual, and gameplay decisions
- Security and privacy checks before sharing artifacts publicly

I am still learning, and these projects are intentionally used as practical environments where I can apply Computer Science coursework, IT experience, and new development tools to real problems.
